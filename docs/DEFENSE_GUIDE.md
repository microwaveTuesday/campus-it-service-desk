# Demonstration script and individual defense preparation
15-minute presentation: 0–2 min problem and SDG; 2–4 min architecture/ERD; 4–9 min staff login, request CRUD, and image upload; 9–11 min admin category CRUD and 403 authorization example; 11–12 min database-backed dashboard; 12–13 min weather/fallback; 13–14 min test/CI evidence; 14–15 min limitations and future work.

10-minute team Q&A: explain JWT flow, Identity password hashes, role vs policy, database FK boundaries, EF Core migrations, external API fallback and file validation. Every member must be able to explain their code.

10-minute individual defense: point to your issue IDs, at least eight commits, two reviewed pull requests, a problem you debugged, the tests you wrote, and trade-offs in your own module. Do not claim scaffold work you did not perform.

Recording: the real team must produce an actual walkthrough no longer than 10 minutes; screenshots and video cannot be fabricated as execution evidence.
